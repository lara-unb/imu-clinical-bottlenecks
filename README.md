# Supplementary material: limiting factors in IMU-based movement measurement

Supplementary material for the narrative review *Where Clinical Confidence Is Lost: Limiting Factors in the Measurement Chain of IMU-Based Human Movement Analysis* (ICORR 2027).

## Contents

| File | What it is |
| --- | --- |
| `material-suplementar.md` | S1 search strings, S2 record counts, S3 eligibility criteria, S4 screening flow and priority rule |
| `docs/index.html` | Same content as a web page (enable GitHub Pages on `/docs`) |
| `data/triagem.csv` | 166 records read at abstract level: id, DOI, title, year, source string, type, decision, criterion, priority |
| `data/consolidado.csv` | 30 articles extracted from full text and analysed in the paper, with measurement-chain link and main error |
| `data/resumo_por_elo.csv` | Counts of articles per link of the chain and per limiting factor |

## Notes

- Screening and data extraction were assisted by a large language model (Claude Sonnet 5.5, Anthropic) under a protocol defined by the first author. The first author screened part 1 of the 413 doubtful titles (104); the LLM alone screened the other 309, and these decisions were not checked individually (see S4). Updated 24 November 2026.
- Full texts and database exports are not included because of publisher and database terms. Records are identified by DOI.
- Some text fields in the CSV files are in Portuguese.
